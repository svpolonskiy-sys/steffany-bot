# VMU Wash&Wheel — сайт онлайн-запису та CRM

Сучасний сайт автомийки (на основі <https://info.vmu.ua/>) з онлайн-записом клієнтів і CRM для менеджерів.
Без зовнішніх залежностей: потрібен лише **Node.js ≥ 22.13** (вбудований `node:sqlite`).

## Запуск

```bash
cd carwash
CRM_PASSWORD='ваш-надійний-пароль' npm start     # http://localhost:3000
```

* Сайт: `/` · CRM: `/crm`
* Якщо `CRM_PASSWORD` не задано, пароль генерується при першому запуску й виводиться в консоль (змінити можна в CRM → «Налаштування»).
* Дані (SQLite) зберігаються в `DATA_DIR` (за замовчуванням `./data`) — робіть резервні копії `carwash.db`.
* Docker: `docker build -t vmu-wash . && docker run -p 3000:3000 -v vmu-data:/data -e CRM_PASSWORD=... vmu-wash`
* За reverse-proxy (nginx/Caddy) віддавайте HTTPS — cookie входу отримає прапорець `Secure` за заголовком `X-Forwarded-Proto: https`.
* Тести: `npm test`

## Як це працює

**Для клієнта** (4 кроки): авто (пошук за маркою → клас авто, або вибір вручну) → послуги за частинами авто
(кузов, салон, скло, колеса, двигун, багажник, двері; кількість для «за 1 шт.») → вільний час (дні з індикатором
завантаження, слоти з кількістю вільних постів, оновлення в реальному часі) → контакти: **ім’я, телефон, марка авто**
(пошта не збирається). Після запису — код, «Додати в календар» (.ics).

**Для менеджера** (комп’ютер, планшет, смартфон): нові записи з сигналом/бейджем, ім’я + телефон (дзвінок одним
дотиком) + авто + послуги + сума, статуси (нова → підтверджено → в роботі → виконано / скасовано / не приїхав),
нотатки, зміна часу/послуг, ручний запис (дзвінок, «з вулиці»), дошка завантаження 4 постів по годинах, база
клієнтів з історією, редагування цін/тривалостей, налаштування робочих годин, вихідних, кількості постів,
експорт CSV.

**Захист від накладок:** сервер сам рахує ціну й тривалість, перевіряє вільні пости в транзакції — двоє клієнтів не
займуть одне вікно; скасовані записи звільняють місце.

## Дані зі старого сайту

Ціни, класи авто (A–F, K1–K3, M1–M2 і списки моделей), тексти, контакти й фото взяті з info.vmu.ua.
Скрипти перетворення: `scripts/build-catalog.py` (прайс → `data/catalog.json`) і `scripts/process-images.py`
(кадрування/тони/колір/різкість фото → webp у `public/img`).

### Припущення, які треба перевірити

На старому сайті **немає** цих даних, тому стоять робочі значення (змінюються в CRM без правки коду):

* Робочі години онлайн-запису **08:00–20:00**, крок **30 хв**, запис мінімум за **30 хв**, горизонт **14 днів**.
* **Тривалість кожної послуги** (мийка 30 хв, прибирання салону 20 хв, хімчистка 4 год тощо).
* Ціни «від» (діапазони на кшталт `500/1000`, `250 (вант) / 350 (пас)`) беруться за мінімальне значення з позначкою «від».
