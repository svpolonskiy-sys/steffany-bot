# ZMOZHU — лендинг v2 (редизайн під конверсію та довіру)

Односторінковий лендинг 30-денної програми супроводу зниження ваги для жінок
(працює через Telegram-бот). Мета сторінки — одна дія: перехід у Telegram-бот
для реєстрації та оплати мотиваційного внеску.

Це **новий варіант сайту**. Усі тексти, фотографії, умови участі, вартість,
правила повернення коштів і юридичні сторінки взяті **побайтово з архіву
`zmozhuredesign20260906.zip`** (джерело правди). Змінено структуру, дизайн,
кольори, типографіку й додано анімації. Логіка змін описана у `DESIGN.md`.

---

## 1. Стек

- **Next.js 14** (App Router, статичний експорт `output: "export"`) + **TypeScript**
- **Tailwind CSS** (кастомні кольорові токени)
- **Framer Motion** (анімації появи, скрол-ефекти, лічильники; повністю
  поважає `prefers-reduced-motion`)
- Шрифти: **Manrope** (текст) + **Cormorant Garamond** (заголовки) через
  `next/font` — без зовнішніх запитів у рантаймі
- Деплой: Vercel / Netlify / Cloudflare Pages / будь-який статичний хостинг

Node.js: **18+** (перевірено на Node 22).

---

## 2. Швидкий старт

```bash
npm install
cp .env.example .env.local      # за потреби змінити посилання на бота
npm run dev                     # http://localhost:3000

npm run build                   # статичний сайт у папці out/
npx serve out                   # локальний перегляд збірки
```

```

  Steps.tsx             # три кроки механіки
  Recognition.tsx       # «Ти вже починала» — текст проявляється при скролі (ScrollWords)

  Pillars.tsx           # Міра (MiraChat), Анастасія, «Поруч є людина»

  Approach.tsx          # підхід + «Чому саме −4%» (CountPercent, DayCycle)
  Investment.tsx        # внесок, три умови (DaysGrid — 30 днів і запас), безпека
  Research.tsx          # JAMA: смужки ростуть при появі (ResearchBars)
  Difference.tsx        # «Чому цього разу інакше»
  FaqSection.tsx, Faq.tsx   # акордеон (дані у lib/faq.tsx)
  Afterwards.tsx        # після програми
  Closing.tsx           # фінальний заклик
  Footer.tsx            # реквізити ФОП, юр. посилання, Visa/Mastercard/WayForPay
  FloatingCta.tsx       # закріплена кнопка (ховається на першому й фінальному екрані)

lib/
  config.ts             # TELEGRAM_BOT_URL + реквізити ФОП (LEGAL)
  faq.tsx               # питання/відповіді FAQ
public/images/          # tanya-hero.jpg, tanya2.jpg, nastya.jpg, tanya.jpg, og-zmozhu.jpg, telegram-bot.png
scripts/check-texts.mjs # перевірка, що всі тексти старого сайту збережені
```

### Де що редагувати

- Тексти секцій — у відповідному компоненті в `components/`
- FAQ — `lib/faq.tsx`
- Чат Міри — `components/MiraChat.tsx`
- Реквізити, посилання на бота — `lib/config.ts`
- Юридичні тексти — `app/<route>/page.tsx`
- Кольори — `tailwind.config.ts` + `:root` у `app/globals.css`

## 5. Перевірка збереження текстів

```bash
OLD_DIR=/шлях/до/розпакованого/старого/сайту npm run build && npm run check:texts
```

Скрипт витягує всі текстові фрагменти зі старого коду (головна, компоненти,
юридичні сторінки, метадані) і перевіряє їх наявність у зібраному HTML та
вихідному коді нового сайту. Поточний результат: **336 фрагментів, 0 відсутніх**.

## 7. Анімації

| Де | Що робить |
|---|---|
| Hero | заголовок з'являється словами з маски; фото відкривається clip-path; паралакс при скролі; чіпи довіри stagger |
| DepositCard | лінія «30 днів» заповнюється, крапка проходить шлях, сума справа набирається до 2000, з'являється галочка |
| Header | тонка лінія прогресу читання; меню з AnimatePresence |
| Recognition | слова проявляються в міру скролу |
| Day | лінія дня заповнюється, «сонце» рухається за скролом |
| MiraChat | повідомлення друкуються по черзі, статус «друкує…» |
| DaysGrid | 30 крапок з'являються по черзі, 3 — запас на пропуск |
| CountPercent | відлік 0 → −4% |
| ResearchBars | смужки 47,4% і 10,5% ростуть |
| FAQ | плавне розгортання відповідей |
| CTA | відблиск при наведенні, стрілка, підйом |

Усе вимикається при системному «зменшити рух».
