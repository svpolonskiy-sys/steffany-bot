# AI Show — «Від ідеї в гуртожитку до глобального продукту за допомогою AI»

Інтерактивна веб-презентація на 80 хвилин для гостьової лекції Сергія Полонського
в Державному університеті «Житомирська політехніка».

- **44 слайди основного шоу** (80:00 за планом) + lobby-екран
- **4 fallback-слайди** (якщо live-демо не працює) — клавіша `X`
- **7 appendix-слайдів** з AI-інструментами для Q&A — клавіша `A`
- Повний storyboard з таймінгом і speaker notes: [`STORYBOARD.md`](STORYBOARD.md)

## Запуск

Просто відкрий `index.html` у Chrome / Edge (подвійний клік). Сервер не потрібен,
інтернет не потрібен — шрифти лежать у `fonts/`, усі анімації вбудовані.

1. Підключи проектор, відкрий `index.html` на екрані проектора.
2. `F` — fullscreen.
3. `P` — відкриває **presenter view** в окремому вікні (перетягни на ноутбук):
   нотатки, наступний слайд, годинник шоу, план vs факт («+2:10» = відстаєш).
4. На lobby-екрані чекаєш, поки зайде зал. `→` — старт, годинник шоу пішов.

Перевірено під 16:9 (1920×1080). На іншому співвідношенні сцена масштабується з полями.

## Керування

| Клавіша | Дія |
|---|---|
| `→` `Space` `PgDn` `Enter` | далі (наступний крок анімації або слайд) |
| `←` `PgUp` `Backspace` | назад |
| `Home` / `End` | перший / останній слайд |
| `12` + `Enter` | перейти на слайд 12 |
| `F` | fullscreen |
| `P` | presenter view (окреме вікно) |
| `N` | speaker notes поверх екрана (для репетиції) |
| `G` | огляд усіх слайдів, клік — перейти |
| `B` або `.` | чорний екран (кнопка «blank» на більшості клікерів) |
| `H` | сховати прогрес-бар і номер слайда |
| `X` | fallback (StudyBuddy AI, запис NotebookLM) |
| `A` | appendix для Q&A |
| `L` | lobby |
| `Esc` | повернутися в шоу з fallback / appendix; закрити оверлеї |
| `?` | шпаргалка клавіш |

Клікер (Logitech, Kensington тощо) працює «з коробки»: він шле `PgUp`/`PgDn` і `B`/`.`.
Клік мишею: права частина екрана — далі, ліва третина — назад.

## Структура

```
presentation/
  index.html              усі слайди + speaker notes (aside.notes) + хуки анімацій
  assets/deck.css         дизайн-система й стилі слайдів
  assets/deck.js          движок: кроки, навігація, presenter view, оверлеї
  fonts/                  Unbounded, Inter, JetBrains Mono (SIL OFL, офлайн)
  images/  video/         медіа для вставки (див. таблицю)
  tools/build-storyboard.mjs   генерує STORYBOARD.md з index.html
  STORYBOARD.md           storyboard: SLIDE · TITLE · ON SCREEN · VISUAL · ANIMATION · NOTES · TIME
```

## Як редагувати

Кожен слайд — `<section class="slide …">` в `index.html`:

- `data-title`, `data-time` (секунди), `data-block` — метадані для таймінгу й presenter view;
- `data-f="N"` на будь-якому елементі — він з’являється на кроці N (клік →);
- `data-out="N"` — зникає на кроці N;
- `<aside class="notes" data-visual="…" data-anim="…">` — speaker notes.

Після змін перегенеруй storyboard:

```bash
node tools/build-storyboard.mjs
```
