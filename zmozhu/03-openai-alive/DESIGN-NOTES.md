# ZMOZHU — новий варіант лендингу

Роль: UX/UI-дизайнер і фронтенд-розробник з фокусом на конверсію в оплату.

Джерело правди: сайт http://localhost:3000/, звірений 6 вересня 2026 року. Основа коду: `zmozhu-source-2026-09-05.zip` — найсвіжіший архів у папці проєкту. Оригінальний архів та сайт на порту 3000 не змінювалися.

## Аудиторія та рішення

За змістом сайту, це жінка, яка вже неодноразово пробувала схуднути, знає базові правила, але втрачає ритм після складного дня. Їй важливо зрозуміти, що від неї вимагатимуть, хто буде поруч, скільки часу займатиме участь і за яких умов повернуть внесок. Вік, дохід та інші демографічні характеристики сайт не встановлює — вони не вигадувалися.

Оригінал має сильне співчутливе повідомлення та реальні фото. Водночас довгі центровані блоки й схожа подача більшості секцій сповільнюють перегляд. Приклад звичайного дня з’являється пізно. Важливі пояснення внеску рознесені на кілька послідовних блоків.

Новий порядок: головна пропозиція → впізнавання ситуації → типовий день → команда та Міра → Тетяна → підхід → внесок і повні умови → дослідження → відмінності → питання → продовження після програми → фінальний заклик.

Глибокий зелений створює спокійний фон, лаймовий акцент виділяє дії та ключові думки. Фото реальних учасниці й експертки збережені. Різні композиції, відступи та контраст між секціями допомагають переглядати довгий текст. На мобільному — одна колонка, великі кнопки, меню та закріплена кнопка після виходу першого екрана з поля зору.

Анімації: одноразова поява секцій, поява фото та підпису, стани кнопок, анімований приклад повідомлень Міри, відлік −4%, ритм дня, відкриття відповідей. Враховано налаштування зменшеного руху. Основний контент доступний навіть без JavaScript.

Не додавати ці відповіді без підтвердження. Назви JAMA / PubMed зараз не є посиланнями: після перевірки конкретного дослідження можна запропонувати прямі посилання для довіри. Твердження про результати й безпеку не посилювалися.

## Як перевірити конверсію

Дизайн — обґрунтована гіпотеза, а не доказ максимальної конверсії. Потрібно порівняти оригінал і новий варіант на зіставному трафіку. Основна метрика — підтверджені оплати / унікальні відвідувачі. Додатково: переходи з конкретних кнопок, початки діалогу з ботом, перехід до оплати, успішні оплати. Для розуміння цінності — початок першого дня та утримання учасниць на 7-й і 30-й день.

Не вважати клік по кнопці оплатою. Події успішної оплати має підтверджувати платіжна система або сервер бота. Нові трекери, аналітичні сервіси й змінені посилання на бот не додавалися.

## Передача розробнику

Стек оригіналу збережений: Next.js 14, React 18, Tailwind, Framer Motion та наявний lockfile. Для приватного перегляду додано статичний експорт. `npm run dev -- --port 3001` запускає незалежну локальну версію. `npm run build` створює `out/`; `npx serve out` може віддавати статичний результат. `NEXT_BUILD_DIR=.next-build npm run build` експортує сайт у `.next-build/`; перед пакуванням цей статичний результат скопійовано до `out/`.

Посилання участі залишене з оригіналу: https://t.me/zmozhu_bot. Його можна конфігурувати через `NEXT_PUBLIC_TELEGRAM_BOT_URL` перед збіркою. Реальна транзакція не виконувалася. Доступність оплати в боті потребує підтвердження власника.

Перевірено: production-збірка й типи; повна рівність текстових фрагментів із поточним сайтом; унікальність якорів; наявність усіх внутрішніх сторінок. Юридичні сторінки та контакти збігаються з архівом побайтово. Адаптивні стилі реалізовані; окремий візуальний тест нового варіанта в браузері не проводився.

Під час фінального відкриття виявлено й виправлено вкладений React-хук у меню. Після виправлення повторно пройшла production-збірка; у браузері підтверджено нормальне відкриття сторінки, розгортання мобільного меню й закриття клавішею Escape.

## Посилення основної пропозиції

За прямим запитом власника посилено тільки перший екран: головний заголовок одночасно пояснює щоденну підтримку та повернення 2000 грн за виконання всіх умов. Рядок внеску замінено помітною карткою із сумою на старті, умовним поверненням, коротким переліком трьох умов, поясненням неповернення за невиконання та посиланням на повні правила. Ці відомості показуються одразу, без затримки анімації.

Попередній заголовок і пояснення збережені в тому самому першому блоці нижче основної дії. Усі секції після hero залишилися побайтово незмінними, усі початкові текстові фрагменти сторінки збережені. Робочий Telegram-бот підтверджено власником. Здатність відвідувачок зрозуміти пропозицію за 3–5 секунд слід перевіряти з людьми; це мета подачі, а не виміряний результат.

### Уточнений порядок першого екрана

На прохання власника повернуто головний заголовок «Ти знаєш, як схуднути. Складніше — не зупинитися». За ним ідуть «Ми поруч щодня», посилена картка фінансової мотивації та основна кнопка. Фінансова картка й решта секцій збережені. Пріоритет: впізнавання своєї ситуації → підтримка → умови внеску.
