# Дизайн-рішення

Концепція: **«Ясність, з якої починається дія»** — розрізнене стає впорядкованим; рух показує цю зміну.

| Референс | Що взято | Власна реалізація |
|---|---|---|
| Wembi | Один впізнаваний візуальний мотив, великі пропорції | SVG-лінії від чотирьох джерел сходяться до картки «Пріоритет на сьогодні»; мотив повторено в OG-картці й логотипі |
| Heron AI | Демонстрація через взаємодію | Демо «Бачить → радить → робить»: сигнал, джерела, погодження, журнал; режим розбіжності блокує погодження |
| Illoca | Теплота, редакційна типографіка | Ivory-фон, тонка сітка лише всередині демо-сцени, один serif-акцент у заголовках (Noto Serif italic) |
| Cartesia | Сценарії в одному вікні | Три вкладки змінюють одну панель однакової структури |
| Legora | Стриманий тон, безпека, єдиний CTA | Секція «Контроль», один CTA «Обговорити ваш процес», прозорий пілот без клієнтських доказів |

Рух: одноразова поява тексту (≤400 ms), одноразове «малювання» ліній hero (~1.2 s), crossfade демо (220 ms), reveal заголовків. Нативний scroll; `prefers-reduced-motion` вимикає все. Без JS видно весь зміст (включно з noscript-версією демо й сценаріїв).
Стилі — CSS variables + глобальний `globals.css` (єдина система, без CSS Modules, щоб не дробити невеликий сайт).
