# Реалізацію завершено; публічний запуск очікує:

1. Домен → `SITE_URL` (canonical, sitemap, OG, indexing).
2. Канал звернень → `CONTACT_WEBHOOK_URL` (+ секрет) і тестове звернення в погоджений канал.
3. Затверджена політика конфіденційності → `NEXT_PUBLIC_PRIVACY_URL`; текст про обробку даних біля форми потребує юридичного погодження.
4. Реальні контакти/юридична назва (за потреби) → `NEXT_PUBLIC_CONTACT_EMAIL`.
5. Затверджений логотип (зараз тимчасовий wordmark + символ).
6. Lighthouse/ручні перевірки з qa-report на реальному середовищі; рішення щодо аналітики та згоди.
7. Спільне сховище для rate-limit, якщо буде кілька інстансів.
