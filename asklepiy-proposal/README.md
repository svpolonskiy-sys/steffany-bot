# Пропозиція Sinaptic для МЦ «Асклепій»

Односторінковий лендінг-презентація (HTML + CSS + мінімум JS), оформлений у стилі asklepiy.com:
бренд-синій `#2b5c8e`, блідо-блакитні секції `#e5ecf6`, сіре тло `#f2f2f2`, білі картки з радіусом 12–32 px.

- Запуск: `python3 -m http.server 8080` у цій папці, відкрити `http://localhost:8080`.
- Шрифти: Montserrat (замість комерційного Gilroy) і Mulish через Google Fonts.
- Логотип і фото Асклепій не використовуються; зображення в `img/` належать Sinaptic.
- Калькулятор у розділі «Лікарі» сценарний, вхідні цифри умовні й редагуються на сторінці.
- Сторінка має `noindex`.
- Моушн: SVG (SMIL) і CSS-анімації потоків даних, шифрування, журналу; вимикаються при `prefers-reduced-motion`.
- Блок про США використовує лише дозволені до публікації факти: без назв клієнтів, імен лікарів і цін.

## Перед відправкою клієнту перевірити
- Формулювання про досвід у США (розділ `#usa`): роль Sinaptic, що саме можна розкривати.
- Контакти, ціни (4 500 € одноразово, від 650 €/міс) і умови (ПДВ, валюта, терміни).
- Цифри Асклепій у блоці статистики взяті з asklepiy.com (25+ років, 170+ лікарів, 2 тис.+ втручань);
  «90+ напрямків» і «7 адрес» пораховано за переліками на сайті.
