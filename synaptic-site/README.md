# Sinaptic: сайт для готелів і сфери гостинності

Статичний односторінковий сайт (HTML + CSS + трохи JS). Збирати нічого не потрібно: достатньо віддати папку веб-сервером.

## Структура

```
index.html        розмітка сторінки (SVG-іконки вбудовані на початку <body>)
css/styles.css    усі стилі, теми (світла/темна), анімації
js/main.js        поява блоків при прокрутці, кнопки «Копіювати» в контактах
img/              фото команди та бейджі PECB
```

## Запуск локально

```bash
cd sinaptic-site
python3 -m http.server 8080
# відкрити http://localhost:8080
```

Файл `index.html` можна відкрити й подвійним кліком, але через сервер ближче до реальних умов.

## Деплой

Сайт повністю статичний. Підійде будь-який варіант: nginx/Apache, Netlify, Cloudflare Pages, GitHub Pages, S3 + CDN. Кореневий файл: `index.html`.

Приклад для nginx (піддомен, наприклад `demo.sinaptic.ai`):

```nginx
server {
    listen 80;
    server_name demo.sinaptic.ai;
    root /var/www/sinaptic-site;
    index index.html;

    gzip on;
    gzip_types text/css application/javascript image/svg+xml;

    location ~* \.(png|css|js)$ {
        expires 30d;
        add_header Cache-Control "public";
    }
}
```

Далі підключити HTTPS (наприклад, `certbot --nginx -d demo.sinaptic.ai`) і DNS-запис для піддомену.

## Зовнішні залежності

- **Google Fonts** (Manrope, Playfair Display) підключаються з CDN у `<head>`. Якщо шрифти не завантажаться, працюють системні (запасні) шрифти. За потреби шрифти можна розмістити на власному сервері.
- Інших бібліотек і сторонніх скриптів немає. Аналітики, cookie та форм зворотного зв'язку на сторінці немає.

## Що редагувати

- **Контакти** (блок внизу сторінки і підвал): пошук у `index.html` за `380677162224` і `sergiy@sinaptic.ai`.
- **Кольори й шрифти**: змінні на початку `css/styles.css` (`:root`). Світла й темна теми перемикаються автоматично за системним налаштуванням користувача (`prefers-color-scheme`).
- **Анімації** зроблено на CSS і SVG (SMIL). Для користувачів із увімкненим «зменшити рух» (`prefers-reduced-motion`) вони вимикаються.

## Примітки для розробника

- Усі стилі в одному файлі, а імена класів глобальні. Додаючи нові компоненти, перевіряйте, що назви не збігаються з наявними (це вже траплялося: збіги ламали вигляд блоків).
- Сторінка адаптивна: перехід на мобільну схему анімацій на ширині 900 пікселів.
- Для кращого вигляду посилань у месенджерах варто додати зображення `og:image` (зараз його немає).
